## 🚀 GitHub Pages の設定方法

1. このリポジトリの **Settings** を開く
2. 左メニューの **Pages** をクリック
3. Branch を `main`、フォルダを `/ (root)` に設定して **Save**
4. しばらく待つと URL が発行されます🎊
